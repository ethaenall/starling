STARLING build 3: the first five seconds

open it.

STARLING fades in. the search bar lights up like a sun. the planets settle onto their orbits instead of just appearing. that was the whole point of this build — it still has to feel like a new tab in the first five seconds, not a dashboard you have to learn.

dusk and night actually look different now. i also made the planet textures smaller so adding a world doesn't hitch, and reduced motion freezes the sky.

and it can be your real chrome new tab. `npm run build`, then load the `dist/` folder unpacked. still no account. still nothing leaves the browser.
